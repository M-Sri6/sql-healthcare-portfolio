# 🏥 Hospital Performance Dashboard – SQL Portfolio Project

## 🎯 Objective
To analyze hospital performance using SQL, focusing on:
- Doctor readmission rates and average length of stay
- Monthly readmission trends over time
- Most common diagnoses by admission volume
- Patient risk classification based on age and readmission history

## 🛠️ Tools Used
- Microsoft SQL Server
- SQL Server Management Studio (SSMS)
